# nutng driver plugin "example-py" (Python)

Created by `nutng plugin new`. `nutng_plugin/` is the nutng plugin SDK;
`nutng_plugin/_gen/` is generated from nut-ng's proto files.

```sh
python -m pip install -r requirements.txt
```

Then add the plugin to nutng.yaml (see the top of plugin.py) and check it
with `nutng plugin info example-py`.
